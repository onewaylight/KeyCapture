유튜브 시청전 재생윈도우에 따라 영역을 지정해 놓습니다.
유튜브 재생후 캡쳐윈도우가 Activate, 그러니까 윈도우에 포커스가 있어야 합니다.
그리고 시청하면서 중요장면에서 F12 키를 누르시면 캡쳐됩니다.

1. 캡쳐한후 어디에 저장할 지 폴더 위치 저장
2. 영역지정
3. 유튜브 재생
4. 캡쳐윈도우에 포커스 주기
5. [F12] 키를 통해 캡쳐


Known Bug.
- 듀얼 모니터의 경우 프로그램이 Active 된 위치에 상관없이 주 모니터의 화면에 포커스 됨.
